# Google Play クローズドテスト運用キット（12人×14日）

- 目的: 個人開発者アカウントの製品版公開要件（**12人が14日間継続してオプトイン**）を満たし、
  あわせて実機プレイテストのフィードバック（生存バランス・通知・おすそわけ）を集める。
- 目標: **7/11 テスト開始 → 最短 7/25 完了 → 7月下旬 製品版公開**（CLAUDE.md のスケジュールが正）。

## 段取り（先にやる順）

1. **Play Console**: アプリ作成 → クローズドテストのトラック作成 → Codemagic `android-release` の AAB をアップロード
2. **Googleグループ作成**（例: `inuneko-testers@googlegroups.com`）→ トラックのテスターに**グループを指定**（個別メールより入れ替えが楽）
3. **フィードバックフォーム**（Googleフォーム・下の質問案をコピペ）を作り、URLを控える
4. 声かけ開始（下の文面）。**15〜18人**集まったら全員をグループに追加 → オプトインURLを配って**一斉スタート**
5. 開始後は Play Console の「テスター数」を**毎日確認**（12人を割ったら即補充。ただし途中参加者の14日は参加時点から）

> 注意: 「12人×14日」は**継続オプトイン**が条件。ギリギリ12人で始めない。
> 製品版申請時に「テストで何を学んだか」を書く審査フォームがあるため、フォームの回答がそのまま材料になる。

## 声かけ文面（コピペ用）

### LINE（友人・家族向け）

> 個人でスマホアプリを作りました🐶🐱
> 「スマホを置くと犬猫が育つ」ゆるい育成ゲームです（広告なし・無料）。
> Google Playの決まりで、公開前に **14日間インストールしたままにしてくれる人が12人** 必要です。
> やることは3つだけ:
> ① このリンクからテスター参加（Googleアカウントで）→ ②アプリを入れる → ③**14日間消さずに**たまに遊ぶ
> 参加リンク: （オプトインURL）
> 感想はここに書いてもらえると嬉しい: （フォームURL）

### X / コミュニティ（相互テスト向け）

> 【テスター募集】スマホを置くと犬猫が育つデジタルデトックス×育成ゲーム「いぬねこ図鑑」🐾
> Google Playクローズドテスト（14日間）のテスターを探しています。広告ゼロ・登録不要。
> 相互テスト歓迎です（あなたのアプリも14日入れます）。リプかDMで！ #テスター募集 #クローズドテスト

## フィードバックフォーム質問案（Googleフォームに貼る）

1. 端末の機種名（例: Pixel 8）
2. 最初の5分で「わからなかったこと」はありましたか？（自由記述）
3. 🍖おすわり と 🐾お散歩 の違いは伝わりましたか？（はい/いいえ＋一言）
4. 数日つかって、ごはん・いのちの減りかたはどう感じましたか？（はやい/ちょうどいい/ゆるい）
5. 通知（おすわり成功・さんぽリマインド）は届きましたか？
6. おすそわけコードを送る/もらうを試せましたか？うまくいきましたか？
7. 気に入った子（品種）・欲しい機能があれば教えてください

## テスト中に開発側が確認すること（実機チェックリスト）

- [ ] 減衰が**前面時間ベース**である体感（「ごはん4〜5日」がカレンダー日数でないこと）
- [ ] ローカル通知（おすわり満了・さんぽ完了・時間指定リマインド）が実機で届く
- [ ] 復帰時の「おかえり」レポートとオフライン進行の整合
- [ ] おすそわけコードの実機コピー/貼り付け（クリップボード権限）
- [ ] 図鑑・きせかえ・もようがえの描画速度（低スペック端末）
- [ ] （終了時）審査フォーム用に「学んだこと→直したこと」を3行でメモ
