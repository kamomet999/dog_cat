## 2つの「課金」を区別する（最重要）

| | 内容 | 可否 |
|---|---|---|
| ❌ 延命・復活の課金 | 死んだ子を金で生き返らせる／寿命を金で延ばす | **永久になし**（DESIGN.md 原則2「責めない」を壊す） |
| ✅ コレクション拡張の課金 | ¥500買い切り1回で「キャラ30種→60種(犬30・猫30)」＋「模様替え10種→50種」を解放 | **採用**（延命ではないので世界観と両立） |

→ 「広告ゼロ」「延命・復活の課金なし」という約束は**不変**。変わったのは「全種が無料」だった点だけ。

## ティア

| | 無料 | プレミアム（¥500 買い切り） |
|---|---|---|
| 収録品種 | **人気メジャーの犬15種＋猫15種＝計30種**（`breeds.js` の tier 無し） | **＋犬15・猫15 ＝ 全60種**（`tier: 'premium'`。全種スプライト絵つき） |

| 広告 | なし | なし |
| 追加課金 | — | なし（買い切り1回のみ） |

- 商品ID: `inuneko_premium_unlock` ／ 表示 `¥500`（`Breeds.PREMIUM`）
- 実装状態: **仕組み・データとも完成**（フラグ `state.premium`・`Engine.unlockPremium()`・図鑑のCTA/解放表示・購入モーダル・60種すべてスプライト絵つき）。残タスクは実機の課金プラグイン接続のみ（v1.1）。
- レアリティは無料/プレミアム両ティアに分散。無料側にもレジェンド級（ウルフドッグ／ベンガル）を残し、**無課金でも「引きの喜び」と図鑑コンプが完結する**。
- 400種構想（`docs/art/breed-master-list.md`）は**将来の拡張アーカイブ**に格下げ。追加するなら絵を先に用意してから（絵のないデータは図鑑に載せない）。

## 課金処理（実購入）

- **MVP/web**: 購入ボタンで即 `Engine.unlockPremium()`（ストア接続なし。検証用。`window.__INUNEKO_IAP__=true` で導線表示）。
- **実機（v1.1）**: Capacitor の課金プラグイン（RevenueCat もしくは StoreKit/Play Billing）で
  `inuneko_premium_unlock`（非消費型）を購入 → 成功コールバックで `unlockPremium()`。
  「購入をふくげん（Restore）」も同プラグインの restore に接続する。
- ストア側の商品登録は Apple/Google の有料アカウント確定後のタスク。
